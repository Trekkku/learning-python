## 🚀 Проекты в репозитории

### 📂 my-first-project
Мой первый демонстрационный Python-проект, настроенный по "всем правилам".

* **Инструменты**: `uv` (пакетный менеджер), `pytest` (тесты), `ruff` (стиль кода), `pyright` (проверка типов).
* **Синтаксис**: Написано с использованием возможностей **Python 3.13**.
* **Качество**: Защищено автоматическими проверками перед коммитами (`pre-commit`).

---

## 🛠️ Как запустить проект локально

1. Убедитесь, что у вас установлен пакетный менеджер `uv`.
2. Перейдите в папку проекта:
   ```bash
   cd my-first-project
   ```
3. Синхронизируйте и разверните изолированное виртуальное окружение:
   ```bash
   uv sync
   ```
4. Запустите тесты, чтобы убедиться, что всё работает:
   ```bash
   uv run pytest
   ```
